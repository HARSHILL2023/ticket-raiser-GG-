## ✨ Overview

CTMS (Complaint Tracking Management System) is a **full-stack MERN application** designed to streamline complaint registration, tracking, and resolution inside residential or organizational environments.

It supports **role-based access control** for:
- 👤 Member (Raise complaints)
- 🧑‍💼 Manager (Handle & update complaints)
- 👨‍💼 Admin (Full system control + analytics)

## ⚡ Features

- 🔐 Secure JWT Authentication
- 👥 Role-based dashboards (Admin / Manager / Member)
- 📝 Raise & track complaints in real time
- 📊 Admin analytics dashboard
- 🔄 Live status updates (Pending → In Progress → Resolved)
- 📱 Fully responsive UI
- ⚡ Fast REST API integration
- 🧠 Clean production-grade architecture
